# TikTok 手选美国首跳 v1.2.0 候选需求

状态为 **candidate**。保留 [v1.1.1](../v1.1.1/REQUIREMENTS.md) 的良心云默认代理、直连规则和提供商合并修复。方案 ID 与版本线延续已有良心云候选。

- L9：`TikTok首跳` 为手选组，仅接受当前 iKuuu 订阅中名称匹配 `美国Z01 | IEPL | x1.5` 或 `美国Z02 | IEPL | x1.5` 的节点。允许节点名末尾的空格或制表符。组内首项为 `REJECT`。首次启用无已保存选择、所选节点消失或两节点都缺失时拒绝 TikTok 流量。常规重启可沿用用户已保存且仍存在的手选节点。
- L10：`TikTok测速` 仅纳入 `TikTok-ISP-Local`，承担 TikTok 连接和专用 DNS。`TikTok-ISP-Local` 的 SOCKS5 通过 `dialer-proxy: TikTok首跳` 连接，Loongproxy 美国静态出口、凭据和 `udp: false` 沿用既有配置。对比首跳时手选后测同一目标并实测播放。

验收包括两个候选首跳的实际可用性、Loongproxy 出口、未选择或节点消失时行为，以及手动／大陆直连和良心云默认代理。节点名称及其 `x1.5` 标签用于筛选，实际流量计费以 iKuuu 为准。

本地以 OpenClash v0.48.002 的合并函数和 Mihomo v1.19.34 测试顶层节点与提供商两种加载方式，验证初始拒绝、手动选中、重启保留选择、所选节点消失及两个节点均缺失时拒绝。目标路由器核心与两条真实线路待验收。
